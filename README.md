## 👾 About Me

I'm **Gilian**, also known online as **Voxxai**, a Software Engineer from the Netherlands.

I enjoy working across the stack, with a particular interest in **backend development, APIs, authentication, automation and system architecture**. Most of my projects start with a simple idea and inevitably end with me wondering how far I can push it.
